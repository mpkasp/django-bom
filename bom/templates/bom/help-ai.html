Connect an AI assistant

An assistant such as Claude can search your parts, read BOMs and propose changes through IndaBOM's MCP server. It acts as you, in your organization, and never has more access than your role. Agents never release revisions or approve requests.

The server address is:

{{ mcp_url }}
{% if oauth_enabled %}

Sign in from your assistant

Add the server, then sign in. Your browser opens, you sign in to IndaBOM as usual, and a page asks what the assistant may do. No token to copy.

Claude Code
claude mcp add --transport http indabom {{ mcp_url }}

Then run /mcp inside Claude Code, choose indabom and select Authenticate.

claude.ai and Claude Desktop

Open Settings → Connectors, choose Add custom connector, enter the address above, then connect and sign in.

Cursor

Add this to ~/.cursor/mcp.json, then choose Connect next to indabom in Cursor's MCP settings.

{"mcpServers": {"indabom": {"url": "{{ mcp_url }}"}}}
{% endif %}

{% if oauth_enabled %}Or paste a token{% else %}Connect with a token{% endif %}

Create a token in Settings → Connected apps under Personal access tokens, copy it when it is shown (it is shown once), and give it to your client. This works with clients that let you set a header, such as Claude Code and Cursor.{% if oauth_enabled %} Connectors in claude.ai and Claude Desktop need the sign-in method above.{% else %} Connectors in claude.ai and Claude Desktop cannot send a header, so they cannot use a token.{% endif %}

Claude Code
claude mcp add --transport http indabom {{ mcp_url }} --header "Authorization: Bearer <token>"
Cursor
{"mcpServers": {"indabom": {"url": "{{ mcp_url }}", "headers": {"Authorization": "Bearer <token>"}}}}

What the assistant may do

  • Read only: look up parts, BOMs and where parts are used.
  • Propose changes for review: also stage changes that a person reviews and applies.
  • Propose and apply changes: also apply changes directly. Viewers can only choose Read only.

{% if oauth_enabled %}You choose the level when you sign in. A token's level is set when you create it.{% else %}A token's level is set when you create it.{% endif %} Applying changes may be unavailable for your organization.

Disconnecting

Revoke the connection or token in Settings → API Tokens. The assistant stops working at once.{% if oauth_enabled %} Connected apps are labeled as such; to reconnect, sign in from the assistant again.{% endif %}
