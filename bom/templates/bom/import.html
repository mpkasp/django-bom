File formats

The first row holds column names; they are case-insensitive and unrecognized columns are ignored. Each type's columns are below, and an export from IndaBOM already uses them.

Parts

Each row is one part. A row that names an existing part (by part number, or by manufacturer part number) updates it; any other row creates a part. Part classes are never changed by an import. Download a template CSV set up for your organization's numbering{% if organization.number_scheme == 'S' %} and part classes{% endif %}, or edit an export of your parts list.

Vendor prices

Each row is one price break, identified by manufacturer part, vendor and minimum order quantity. A matching price is updated, any other row creates one, and parts are never created. Download a template CSV, or edit an export of your vendor prices.

Bill of materials

Each row is one BOM line. Parts and revisions are created if they don't exist, or updated if they do. Released revisions are added as they are and Obsolete revisions are skipped. When a sub-assembly has rows beneath it in the file, its BOM is set to match those rows; a sub-assembly listed without rows beneath it is left alone. Vendor price columns are ignored. {% if organization.number_scheme == 'S' %} Download a sample CSV {% else %} Download a sample CSV {% endif %} or edit an indented BOM export.
